# Phase567 — path-ordered curvature candidate

This deterministic, zero-sampling phase materializes and tests a study-local
second-order BCH curvature candidate on a composable oriented face path. The
candidate changes only the ordering of the three bracket pairs diagnosed by
Phases565-566; the registered core curvature assembler remains byte-unchanged.

The phase checks the exact signed correction, the common linear chain term,
orientation reversal, a commuting null, analytic linearization, transpose
duality, finite group controls, and second-versus-third-order weak-field
behavior. It also performs topology-only controls on the frozen extent-three
lattice shape without reading pilot configurations or running sampling.

A passing terminal means only that the versioned candidate is machine-ready
for a separate downstream counterfactual evaluation. It does not select a
source convention, repair an earlier run, open a source-gated phase, authorize
production, or support a physical-unit claim.
